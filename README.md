## Learning Path

A practical progression is:

1. Begin with **Panel Sleuth** to practice web-panel investigation.
2. Explore **AppSecrets in the Crawl** for application-secret discovery concepts.
3. Continue with **Proxy Trails** and **Prime Proxy Pursuit**.
4. Study SOCKS concepts with **SOCKS Sessions**.
5. Practice credential-focused investigation with **Prime Proxy Credentials**.
6. Explore CMS security using **Theme Hijack RCE in CMS**.
7. Study browser-side security concepts through **Cookie Snatch Hotel** and **XSS Snare: Cookie to Shell**.
8. Continue with **Prime Panel Breach**.
9. Finish with **Prime Shift Hotel Root Chain** and **Backup Vault Breach**.

## How to Use the Labs

Use these cybersecurity and CTF labs only in environments where you have explicit authorization.

Recommended workflow:

1. Read the individual lab objective and requirements.
2. Identify the stated target and scope.
3. Perform reconnaissance systematically.
4. Record hosts, services, applications, paths, and observations.
5. Map findings to the security concept represented by the challenge.
6. Test only within the authorized lab environment.
7. Document your methodology and lessons learned.
